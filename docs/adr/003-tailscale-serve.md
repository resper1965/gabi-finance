# ADR-003 · `tailscale serve` + socket Unix no lugar de Cloudflare Access e nginx
- **Contexto:** o handoff previa túnel Cloudflare + JWT. A VPS não tem cloudflared e já tem Tailscale. Revisão: qualquer processo local (OpenClaw, Paperless, Buzz) poderia forjar `Tailscale-User-Login` em `127.0.0.1:8080`.
- **Decisão:** a API escuta em **socket Unix** `/run/gabi-brain/api.sock`, numa pasta 0700 do serviço (`RuntimeDirectory`); `tailscale serve unix:/run/gabi-brain/api.sock` dá TLS e injeta `Tailscale-User-Login`. Sem porta TCP. `--no-proxy-headers` (o uvicorn não pode trocar a origem por `X-Forwarded-For`). TCP local só em dev/teste (`GABI_PERMITE_TCP_LOCAL=1`).
- **Consequência:** só o `tailscaled` (root) e o serviço alcançam o app. O arquivo do socket é 0666 por imposição do uvicorn; a barreira é a pasta 0700. Diagnóstico: `curl --unix-socket /run/gabi-brain/api.sock http://localhost/api/saude -H 'Tailscale-User-Login: …'` (como `gabibrain` ou root).
- **Quando reverter:** se o app precisar sair do tailnet. Nunca usar `tailscale funnel`.
