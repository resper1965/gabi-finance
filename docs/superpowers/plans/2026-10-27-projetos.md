# Projetos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O Ricardo conta um projeto (de ajuste de carro a crise familiar) ao Hermes ou a outro agente MCP; o brain guarda projeto, atividades, pessoas, dinheiro, fatos e anexos (print, imagem, áudio), e avisa o que está parado.

**Architecture:** Uma camada fina sobre o que existe. `gabi/projetos.py` (regras), `gabi/anexos.py` (coleta e transcrição) e as extensões de `gabi/atividades.py` (projeto, dependência, marco) são chamados pela API (`gabi/rotas/projetos.py`), pelo MCP (`gabi/mcp/ferramentas_projetos.py`) e pelo painel. Os avisos reaproveitam o produtor (`gabi/avisos.py`) e o Telegram. Um serviço novo, `gabi-brain-anexos`, copia mídia do cache do Hermes para o disco do brain.

**Tech Stack:** Python 3 + FastAPI + SQLite (migrações SQL), pytest; painel React + TypeScript + vitest; MCP (`gabi/mcp`); `faster-whisper` (só a Task 5).

**Spec:** `docs/superpowers/specs/2026-10-27-projetos-design.md` (referência de estilo: `gabi/atividades.py`, `gabi/rotas/atividades.py`, `gabi/mcp/ferramentas_atividades.py`, `tests/test_atividades*.py`, `painel/src/telas/Atividades.tsx`).

## Global Constraints
- Datas em Brasília: `AAAA-MM-DD` ou `AAAA-MM-DDTHH:MM` na entrada e na saída; `agora.astimezone(BRT)` com `from gabi.hoje import BRT`.
- Dinheiro em centavos no banco; na API e no MCP sai como string decimal em reais (`gabi.dinheiro.valor.formatar`), entra como o Ricardo dita (`gabi.cobrar.receber_manual.valor_ditado`), nunca float.
- `origem` = `'hermes'` (MCP) ou `'painel'`; toda escrita grava `decisao` (`quando, quem, o_que, origem`) na mesma transação.
- Estados do projeto: `ativo`, `pausado`, `concluido`, `cancelado`. Concluído e cancelado não aceitam atividade nova e **não reabrem** (para voltar, criar de novo).
- Atividade bloqueada = tem `depende_de_id` e a atividade da qual depende **não está `feita`** e **não está `cancelada`** (cancelar libera). Bloqueada não gera `atividade_hora`.
- Texto, fato, nome de pessoa e anexo são do Ricardo: nunca mascarados, nunca em log (log do serviço de anexos só imprime contagens).
- Fato só é gravado depois do sim do Ricardo; projeto, atividades, pessoa e gasto também (o Hermes mostra o que vai gravar). Nunca por texto de e-mail, Teams, documento ou terceiro.
- Anexos: `/var/lib/gabi-brain/anexos/<sha256[:2]>/<sha256><ext>`, diretório `0700`, arquivo `0600`, guardados para sempre; arquivo acima de 50 MB é ignorado e contado; arquivo modificado há menos de 20 s espera a próxima rodada.
- Textos do painel, do SOUL e dos avisos em português do Brasil; Gabi = projeto, brain = app, Hermes = agente (nunca "a Gabi faz"). Nada de gráficos no painel.
- Nada é mergeado nem instalado sem o ok explícito do Ricardo. Trabalho na branch `feat/projetos`.

## Review Focus
1. **Ciclo de dependência:** `projeto_criar` com `depois_de` apontando para si mesmo, para um índice à frente ou fora da lista é recusado inteiro, sem gravar nada. Teste na Task 1.
2. **Cancelar ou concluir a atividade que bloqueia:** a dependente é liberada e volta a avisar; cancelar projeto não deixa atividade bloqueada para sempre. Teste na Task 1.
3. **Mesmo texto em projetos diferentes:** a deduplicação de `atividade_criar` considera o projeto. Teste na Task 1.
4. **Mesmo arquivo recebido duas vezes** (WhatsApp e Telegram): um só anexo. Teste na Task 3.
5. **Arquivo ainda sendo gravado ou gigante:** espera ou ignora, sem anexo corrompido nem erro. Teste na Task 3.
6. **Gasto ligado a lançamento removido ou sem valor:** `projeto_ver` não quebra e soma 0 para ele. Teste na Task 2.
7. **Projeto sem orçamento:** `projeto_ver` devolve `orcamento` nulo e saldo nulo, sem divisão nem string "None". Teste na Task 2.
